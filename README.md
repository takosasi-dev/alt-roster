# ソシャゲ複数アカウント管理(AltRoster)

> **開発中。実機では未確認。**
> ビルドと単体テストは通していますが、実際の端末やエミュレーターでは一度も動かしていません。
> 通知・ウィジェット・ロック・ファイルの選択などは、端末で確かめるまで「動く」とは言えない状態です。

複数のソーシャルゲームを並行して遊ぶ人のための、個人用の Android アプリです。
ゲームごとのアカウント、スタミナの回復、イベントの期限、デイリー・ウィークリーのタスク、課金の記録を 1 つにまとめ、
満タンや期限を通知で知らせます。

- **完全オフライン**。インターネットの権限を持っていません。ゲームのサーバーにも、ほかのどこにもつなぎません。
- **手で入力した記録だけ**を扱います。ゲームへの自動のログイン、画面の読み取り、操作の自動化はしません。
- **パスワードや引き継ぎコードは保存しません**。アカウントごとに「ログインの手がかりのメモ」を書けますが、
  認証に使える情報を書く欄ではなく、暗号化もしていません(入力欄にその旨を表示します)。
- ゲームの名前は利用者が入力します。実在のゲームの名前・画像・アイコン・ロゴ・音は同梱していません。

### 作っていない物・割り切った物

- タスクの表示順の入れ替え(登録した順に並ぶ)
- 復元の取り消し(復元は今の記録を全部置き換える。置き換える前に件数を確かめる画面は出る)
- アプリを裏に回して戻ったときの再ロック(ロックがかかり直すのは、アプリのプロセスが終わったあと)
- ゲームごとの時間帯の指定(タスクのリセットは、端末の時刻で数える)
- DB の移行のテスト(版 2 を作るときに書く)

## 権限と、その理由

| 権限 | 理由 |
|---|---|
| `POST_NOTIFICATIONS` | スタミナ・期限・ダイジェストの通知を出す(Android 13 以降は許可したときだけ) |
| `SCHEDULE_EXACT_ALARM` | 満タンや期限の時刻ちょうどに知らせる。許可が無い端末では、おおよその時刻で知らせる(どのくらい遅れるかは端末しだいで、未確認) |
| `RECEIVE_BOOT_COMPLETED` | 端末の再起動で消えるアラームを、起動のあとに仕込み直す |

このほか、ウィジェットのライブラリ(Jetpack Glance が内部で使う WorkManager)が、ビルドの時に次の 3 つを自動で足します。
アプリのコードからは使っていません。

| 権限 | 足している物 |
|---|---|
| `WAKE_LOCK` / `FOREGROUND_SERVICE` | ウィジェットの描き直しの処理(WorkManager) |
| `ACCESS_NETWORK_STATE` | WorkManager(通信の状態を読めるだけで、通信はできない) |

`INTERNET` の権限は宣言しておらず、できあがった APK のマニフェストにも入っていません。
ストレージの権限も使いません(バックアップの保存先は、端末のファイルの選択の画面で選びます)。

## ビルドの手順

必要な物: JDK 17、Android SDK(compileSdk 35)。

```
./gradlew assembleDebug
```

APK は `app/build/outputs/apk/debug/` にできます。テストは次のとおりです。

```
./gradlew :core:test testDebugUnitTest lintDebug
```

構成は 2 つのモジュールです。

- `:core`(Kotlin/JVM): スタミナの回復、リセットの時刻、通知の時刻の決め方、集計、バックアップの形式と検証。Android に依存せず、単体テストがここにある
- `:app`: 画面(Jetpack Compose)、Room、通知、ウィジェット、バックアップの入出力
